# Contributing to Dining Philosophers Project

Thank you for considering contributing to this project! 🎉  
We welcome all improvements — from fixing bugs to enhancing documentation or adding new features.

---

## 🧩 Project Overview
This project demonstrates the **Dining Philosophers Problem** using **C, pthreads, and mutex synchronization**.  
It is designed for educational use in **Operating Systems and concurrency concepts**.

---
